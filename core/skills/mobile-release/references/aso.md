# Store listing and ASO

ASO improves discoverability and conversion; it cannot guarantee rankings or downloads, and rules differ by store. Never promise outcomes.
- **Metadata:** accurate title, subtitle/short description, long description, keywords (App Store keyword field has a limited length; Play has none, but keyword stuffing violates policy). Character limits change; read the current store docs.
- **Honesty:** listing must match app behavior; no misleading claims, competitor names, or unverifiable superlatives.
- **Visuals:** icon, screenshots in required sizes, preview video; lead with the core value; localize screenshots/text for priority markets.
- **Localization:** translate listing per market, not only the app; check keyword research per locale.
- **Ratings/reviews:** use the official in-app review prompt at a positive moment, never incentivize ratings; respond to reviews.
- **Conversion experiments:** use the store's built-in experiment tools; change one thing at a time; need sufficient sample size.
- **Deep links / web:** website landing pages with smart app banners/app links.
- **Measurement:** store console analytics (impressions, page views, conversion), attribute installs via approved methods respecting platform privacy rules.
- Implementation of SEO for the marketing site belongs to the SEO skills once available.
