# On-page SEO and content strategy

Detect first: CMS or framework and where titles/headings/meta are produced, existing templates, target audience and markets, current content inventory, available data (Search Console queries, analytics, keyword research exports). Follow the existing voice and templates; do not rewrite content wholesale without being asked.

## Principles
- Never promise rankings, traffic or click-through gains. Search engines decide how pages are titled and snippeted; our job is clear, accurate, useful pages that match a real user need.
- Label advice **[Requirement]** / **[Guideline]** / **[Practice]** as in `seo-technical`. Length limits for titles and descriptions are display heuristics, not rules.
- Write for the user's intent first. No keyword stuffing, hidden text, doorway pages, scaled low-value content or copied text; these conflict with search engine spam policies [Requirement, verify current policy].
- Use data, not guesses: query and page data from Search Console, analytics, site search; say when data was unavailable.
- Content quality signals (expertise, accuracy, sourcing, authorship, freshness where relevant) are evaluation concepts described in search engine guidance, not a checklist that guarantees an outcome.
