---
name: audit
description: "Use when the user asks for an overall audit or health check of a codebase (architecture, security, performance, quality). Read-only, scoped, with findings prioritized by severity."
---
Inspect the project and state the audit scope. Gather evidence before conclusions. Prioritize findings by severity, likelihood, impact, and remediation effort. Do not make changes, run destructive tests, or access production systems unless explicitly authorized.
