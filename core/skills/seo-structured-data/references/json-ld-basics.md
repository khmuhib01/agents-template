# JSON-LD basics

- **Format:** [Guideline] Google recommends JSON-LD; microdata/RDFa are supported but harder to maintain. Place `<script type="application/ld+json">` in `<head>` or `<body>`; markup can be generated by server code or client JS, but server-rendered is safer.
- **Structure:** `@context` `https://schema.org`, `@type`, properties. Use an `@graph` with `@id` references to connect entities on a page (WebSite, Organization, WebPage, Article, BreadcrumbList) instead of repeating them. Stable `@id` values (URL plus fragment) allow cross-page references.
- **URLs and dates:** absolute URLs, ISO 8601 dates with timezone, ISO 4217 currency codes, enumerations as schema.org URLs (for example `https://schema.org/InStock`).
- **Images:** crawlable, indexable image URLs of sufficient size; match the page's main image where relevant.
- **Escaping:** serialize with the language's JSON encoder, then make it safe inside HTML (escape `<`, `>` and `&`, or use framework helpers); never concatenate unescaped user content.
- **One source of truth:** build a typed generator (function or class) per type, fed by the same model/CMS entity as the visible page; unit-test output shape; no copy-pasted static JSON for dynamic pages.
- **Plugins/themes:** WordPress SEO plugins, Next.js SEO packages and CMS modules may already output schema. Audit existing output first, extend through the plugin's filters, do not add a second conflicting block.
- **Nesting vs graph:** simple pages can nest; complex pages use `@graph`.
- **Language and locale:** `inLanguage`, localized names per language version of the page.
- **Framework patterns:** Next.js: render a script tag in a server component with the JSON string; Laravel: Blade partial with `@json` or `json_encode` flags; WordPress: through the SEO plugin's schema filters or `wp_head` action with `wp_json_encode`; React SPA: only if prerendered or server-rendered, otherwise crawlers may miss it.
- **Size and performance:** keep blocks small and relevant; do not mark up every property available.
