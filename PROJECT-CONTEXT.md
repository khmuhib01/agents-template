# Project Context: agents-template

Snapshot of v1.22.4 (2026-11-22), built from repository inspection. Facts below were read from files; the Unknowns section lists what was not verified.

## What it is
A generator, not an app. `init.mjs` reads a target project's `project.config.yml` and writes `AGENTS.md`, `CLAUDE.md` and `.claude/` into it. This repo's own `.claude/` is generated output; do not edit it by hand.

## Stack and runtime
- Plain Node 18+ ES modules, zero dependencies, no `package.json`.
- Own YAML-subset parser in `lib/yaml.mjs`.
- CI matrix: ubuntu/macos/windows x Node 18/22.

## Layout
| Path | Role |
| --- | --- |
| `init.mjs` | Orchestrator (`main()` at line ~300; the only place that reads `process.argv`) |
| `lib/` | Pure, side-effect-free parts: yaml, render, scaffold, routing, validate, orch-* |
| `templates/` | `AGENTS.md`, `CLAUDE.md` templates for generated projects |
| `core/` | Copied into projects: `skills/` (~70), `agents/` (10), `hooks/`, `rules/`, `skill-map.json` |
| `global-skills/` | Slash commands: agent-init, agent-setup-scaffold, agent-update |
| `skills/`, `.claude-plugin/` | Generated by `build-plugin.mjs` from `global-skills/` and `VERSION` |
| `orchestrate.mjs` | Drives a real `claude` CLI: plan, implement, test, repair (opt-in, costs money) |
| `install-global.mjs` | Installs global skills; ownership tracked by a manifest |
| `evals/`, `bench.mjs`, `bench-cost.mjs` | Evaluation and cost benchmarks |
| `test.mjs`, `test-helpers/fake-claude.mjs` | Smoke suite and a fake CLI |

## Commands
- `node test.mjs` (smoke suite; `--list`, `--only <text>`). Run before marking work complete.
- `node init.mjs --target <dir> [--dry-run|--scaffold]`
- `node build-plugin.mjs [--check]`
- `node bench.mjs`, `node evals/run.mjs`
- Spend money, never run without asking: `bench-cost.mjs`, `orchestrate.mjs` with a real `claude`.

## Conventions
- `lib/` stays dependency-free; target/dry/here come in as arguments.
- Template engine: double-brace variables and if/else/endif, no nested if.
- New stack = `core/skills/<name>/SKILL.md` + an entry in `core/skill-map.json`.
- Bump `VERSION` for changes that should show as an upgrade; add a `CHANGELOG.md` entry; update `README.md` and `project.config.example.yml` when adding config keys.
- Tests enforce: no placeholders left in generated md/json, idempotent re-run (0 created, 0 updated), invalid type and forbidden words exit non-zero.

## Git and CI
- Flow: `feat/* -> dev -> main`. `main` and `dev` are protected (PR only, CI required, no force-push). Only `dev` may merge into `main` (`guard-main.yml`).
- `test.yml`: `node build-plugin.mjs --check`, then `node test.mjs`. Stale `skills/` or `.claude-plugin/` fails CI.
- Pre-commit hook regenerates and stages those files. Enable once per clone: `git config core.hooksPath .githooks`.
- No deploy; pushing does not deploy.
